# Django Calculator App

A simple multi-app Django project with:
- Calculator
- To Do List

## Features
- Interactive calculator (JS based)
- Bootstrap UI
- Multi-app navigation

## Setup

```bash
git clone https://github.com/Urmila29/CODING-SAMURAI-INTERNSHIP-TASK.git
cd CODING-SAMURAI-INTERNSHIP-TASK
pip install django
